## Week 1 - History
[Week 1 Lecture Notes](https://github.com/kamrik/IntroText/blob/main/summaries/short/Week01-History.md) 

### Pre Writing and First writing
- 30,000 years ago cave paintings 
- 20,000 years ago ishango bones with tally marks
- 5000 years ago Clay tablets in Mesopotamia (First writing)
- Cuneiform: Wedge-shaped marks pressed into clay (First writing)
### Number systems
- Babylonian numerals uses 2 types of wedges (one meaning 10 and one meaning 1) base 60
- Egyptian: symbols for powers of 10
- Roman: Subtractive notation (roman numerals)
### Evolution of Writing
- Sumerian Language: Used syllabic writing
- Epic of Gilgamesh: Early Literature (~4000 years ago)
### Development of Printing
- Early printing techniques : Cylinder seals used for stamping, Woodblock printing (868AD)
- Movable type: invention enabled rearranging characters for different texts. Gutenberg Press revolutionized printing with metal movable type.
- Impact of printing: Economical & Cultural, reduced book prices and facilitated renaissance and reformation

## Week 2 - Bits and Bytes
[Week 2 Lecture Notes](https://github.com/kamrik/IntroText/blob/main/summaries/short/Week02-Bits-and-Bytes.md)

### Number Systems
- Binary: Used in computing, only using digits 0 or 1 (base 2)
- Decimal: Standard human number system using digits 0 to 9 (base 10)
- Hexadecimal: Uses digits 0-9 and letters A-F (base 16)
- Byte: group of 8 bits
### Memory types
- Volatile Memory: RAM, loses data when power is off
- Non volatile memory: SSD/HDD, retains data without power
### Number Representation
- Signed Numbers: Range from -128 to 127 for 8 bits
- Unsigned Numbers: Range from 0 to 255 for 8 bits
- Fractional Numbers: Represented using scientific notation with 2 integers
### Text Representation
- ASCII Table: Maps numbers to characters
- Control codes- Non printable characters for controlling functions
### Practical Applications
- Text editor: Displays bytes as characters using ASCII
- File Structure: files are a sequence of bytes organized in directories

## Week 3 - Text Structure
[Week 3 Lecture Notes](https://github.com/kamrik/IntroText/blob/main/summaries/short/Week03-Text-Structure.md)
### Text Structure
- Historical Context: Early text structures in printing and typewriting (i.e ancient text with commentary)
### Key Concepts
- Lines and indentation: lines are fundamental in coding, indentation helps in visual understanding
- Paragraphs: Important in HTML for text presentation
### Markup Languages
**Markdown (MD)**

Markdown rendering converts raw text to a formatted view.

Some markdown syntax for formatting:
  - Titles: '# Title', '## Subtitle'
  - Italic: '_italic_"
  - Bold: '**bold**'
  - Lists: '* item' or '- item"

**Hypertext Markdown Language (HTML)**

More detailed than Markdown

HTML Tags:
  - \<ul> - Unordered List
  - \<ol> - Ordered List
  - \<li> - List item (used in both ul and ol)
  - \<p> - Paragraph
  - \<strong> - Bold
  - \<h1> - Heading tag (h1-h6)

**Escaping and Special Characters**

- MD Special Characters:
  - Non-alphanumeric symbols like '@', '#', '$', "&', '*'.
  - Escaping in MD using '\\' to escape so '\\#' will display '#'
- HTML Escaping:
  - Use '\&lt;' for '<'
  - Use '\&gt;' for '>'
  - Use '\&amp;' for '&'
